# Context sentence data

The built-in context sentences are selected at build time from the
[Tatoeba Project](https://tatoeba.org/) corpus. Tatoeba text is available
under the Creative Commons Attribution 2.0 France license. The bilingual
selection pass uses the Tatoeba Mandarin-English export distributed by
[OPUS](https://opus.nlpl.eu/Tatoeba.php).

Only the selected English sentences are included in this project. The source
corpus archives are build-time inputs and are not distributed with the site.

Attribution: Tatoeba contributors, https://tatoeba.org/
